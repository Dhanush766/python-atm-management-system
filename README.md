# Python ATM Management System

A console-based ATM Management System developed using Python.

## Features

- Deposit money
- Withdraw money
- Balance enquiry
- Input validation
- Custom exception handling
- Menu-driven application

## Technologies Used

- Python

## Python Concepts Used

- Functions
- Modules
- Exception Handling
- Custom Exceptions
- Match-Case
- While Loop
- Conditional Statements

## How to Run

1. Download or clone this repository.
2. Open the project folder in PyCharm or VS Code.
3. Run:
python ATMMainProject.py
